# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 身份归并约定

合并场景可选列：`source`（old/legacy 为旧系统，new 为新系统）、`insured`（被保人）、`renewal_of`（续接原保单号）。三列均缺席时身份等同保单号，不启用归并。归并发生在责任映射阶段，结果写入 `contract_id`（归属合同）与 `owner_id`（核算归属），选版、切片、重算、对账与结案下载共用同一归属。

归并规则按序确定，失败一律隔离 IDENTITY 并计入对账，不丢弃记录：

1. 续接链优先：`renewal_of` 指向原保单（按合同身份精确匹配，其次按单号唯一匹配），整条链归属链根即原保单核算，应收与已收按链汇总。续接环、悬空引用、多义引用、同一合同多个续接目标均隔离 IDENTITY。
2. 同号多被保人拆分：同一保单号对应多个被保人时按被保人拆分，含新系统记录的一方保持原号（以新系统为准），旧系统侧归属 `单号@old`；新系统内部或旧系统内部同号多人属矛盾，整组隔离 IDENTITY。碰撞单号下被保人缺失的记录无法归属，隔离 IDENTITY。
3. 同人同号跨系统合并为同一合同；仅 `source` 列不同的迁移副本视为完全重复去重，保留新系统侧，计入完全重复。
4. `source` 值无法识别（非 old/legacy/new）隔离 IDENTITY。

归并为输入的纯函数：同源输入重跑 run_id 不变，不新增保单或补退；复核版本不变更规则版本。
